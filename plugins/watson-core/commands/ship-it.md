# Ship it

1. Run the project's test suite. Report pass/fail counts only.
2. Run the linter and formatter.
3. Summarise the diff against the default branch in three bullets.
4. Flag anything unfinished: TODOs added, skipped tests, commented-out code.
5. Stop. Do not push or merge without being asked.
